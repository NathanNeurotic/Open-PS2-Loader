WHY VENDORED: the SDK prebuilt BDM embeds a cache that ignores failed/short
refills, publishes stale data as a successful read, and caches it at the new
LBA. ATA cannot fix that cache contract. Building BDM here makes the source
and correction consistent across all toolchain flavors. This is a separate
confirmed defect; a destructive write from it has not been demonstrated.

LOCAL CHANGES:
- Invalidate an entry before refill and publish it only after all 8 sectors
  are read. Propagate failures and turn short refills into -EIO.
- Bypass read-ahead for valid requests at the device end and for sector sizes
  other than 512 bytes; reject out-of-capacity requests without overflow.
- Handle cache allocation failure; existing BDM falls back to direct access.
- MBR/GPT probes require a complete one-sector read. Free the MBR allocation
  on read failure.
- Copy block_device metadata using the installed header's complete structure,
  then assign wrapper callbacks. This preserves optional appended fields and
  builds with older official SDK headers without a .path member.
- Validate partition-local and parent-device ranges before read/write address
  translation; include the last sector of valid GPT partitions.
- Size MBR/GPT probe buffers to the advertised sector size, rejecting invalid
  sizes before allocation. Reject malformed table/partition geometry and
  unsupported GPT entry layouts; inspect GPT only on whole devices.
- Release exports when event/thread startup fails. Restore the license citation's
  section symbol, which was previously a replacement character.
- Fork Makefile, exports-first for iopfixup compatibility. Export ABI stays 1.1.

Unchanged: mount worker, priority, transport drivers and FAT/exFAT driver.
This does not implement read-only discovery, GPT CRC validation, cache-wide
synchronization, or general filesystem metadata validation.
