WHY VENDORED: the application previously embedded the SDK's prebuilt
ps2hdd-osd.irx. Its partition transfer checks add 32-bit offsets before
establishing that the partition and relative request fit. A lower ATA
capacity check cannot identify an address that already wrapped in APA.
Building the same OSD/ATAD variant here applies the checks in every flavor.
This is fault containment for invalid metadata/requests; it does not
establish what caused the reported loss of access or repair affected media.

LOCAL CHANGES:
- hdd_fio.c: check device capacity, complete partition extent and relative
  request with subtraction before translating the sector. Preserve main
  and subpartition reserved-sector restrictions. Reject invalid direction
  and subpartition indexes; zero-length valid transfers do no device I/O.
- hdd_fio.c: bound the file view's position and signed byte count, clamp to
  its existing EOF, and check the partition before device I/O. Keep position
  update under fioSema and preserve it on device errors.
- hdd_fio.c: reject an on-disk subpartition count above APA_MAXSUB before
  narrowing it into the open file slot; bound size/start metadata queries.
- journal.c: preserve the saved journal and return an error if its read or
  replay fails; reject invalid magic/count and handle scratch allocation
  failure. Reset only after successful replay. Initialize the in-memory
  journal magic for the first transaction; bound append count before I/O.
  Provide apaJournalAbort to clear in-memory journal state on aborted staging.
- cache.c: enforce transaction atomicity in apaCacheFlushAllDirty: abort
  destination writes on staging/commit failure, halt destination writes and
  preserve the on-disk recovery journal on destination write failure, require
  a cache flush barrier before resetting the journal, and clear dirty flags
  only after complete success. apaCacheTransfer clears dirty flags only on
  success. apaCacheGetHeader and apaCacheAlloc skip dirty entries on the free
  list to prevent silent metadata clobbering.
- apa.c: free the cache entry on read failure in apaGetPartErrorSector; save
  partition coordinates before freeing clink in apaInsertPartition; save next
  and device before freeing clink in apaGetNextHeader; save header->next before
  freeing clink1 in apaDeleteFixNext; save prev before freeing clink in
  apaDelete.
- hdd_fio.c: compare passwords before freeing clink in apaOpen; save the
  partition sector before freeing clink in hddFormat; remove duplicate
  SignalSema calls in apaRename; validate nsub against APA_MAXSUB in apaRemove,
  fioGetStatFiller, ioctl2AddSub, and ioctl2DeleteLastSub.
- hdd.c: validate clink_this from apaCacheGetHeader before dereference in
  hddAddPartitionHere.
