PC CARD CompactFlash (early Japanese PS2)

Experimental native CompactFlash game loading for Japanese SCPH-10000, SCPH-15000 and SCPH-18000 PC CARD consoles is included in rebuild/main after PR #955. It is off by default and has not been verified on real consoles.

Implementation is not a hardware pass
Use a release whose source includes #955, or a specifically requested test artifact. Report the exact build and model; host tests and build CI do not establish game, IGR or adapter compatibility.

Required hardware

Early Japanese PS2 with PC CARD and a compatible CF/ATA bridge. Eligible ROM versions 0100/0101/0120 are hints only; the driver must also verify controller revision 0x20, idle/present media, CF CIS, ATA identity/capacity and a bounded MBR FAT32/exFAT partition. Expansion-bay PS2s, Slims, DTL TOOL and DESR DVR machines are not covered.

Experimental test instructions

  1. Launch RiptOPL from a physical memory card or independent device. Avoid inheriting PC CARD ownership from another launcher.
  2. Use MBR FAT32 or exFAT, with a known-good ISO under DVD/ or CD/. Standard ART/ and CFG/ folder naming also applies.
  3. Enable PC CARD CF (experimental) in Game Sources. It defaults to off. For initial testing leave HDD and network sources disabled; save settings and cold-restart.
  4. Use the distinct CF/BDM game source and the native PS2 core. Use a physical memory card; remove any assigned CF VMC.
  5. Record cold/repeat boot, game/FMVs, Mode 6, IGR exit/relaunch, refresh and any adapter errors separately on each model.

Ownership and restrictions

  • PC CARD CF and DEV9/HDD/network cannot simultaneously own the shared slot. Restart to release an established CF session.
  • Read-only game driver. No CF-hosted VMC, CF automatic VMC, PS1/Ember/POPStarter, external Neutrino, live RA telemetry or DECI2 game debugging.
  • Failed initialization is retried after a CF toggle change or explicit refresh; unrelated hotplug events do not continuously retry it.
  • Physical media handling, repeated IOP resets, FMVs and IGR require console verification.

Source provenance and developer credit

The CF backend adapts mihhru/PS2CF 1.0 (pinned reference SHA 9b6ed3702b59a87512426952e003125a5b4f0e3c). Driver notices and licenses remain with the integrated source. No firmware, FMCB image, proprietary game data or GPL mymc code is imported.

Read the technical notes and review and test artifacts. For Sony DVR hardware use the separate PSX DVR guide.
