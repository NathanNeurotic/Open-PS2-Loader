Settings Reference

Every settings screen in RiptOPL, in the order the loader shows them. Each table lists the rows exactly as they are labelled on screen, with their values and what they do. Rows that open another screen are marked [sub-screen]. Per-game options are on the Per-game Settings page.

Where settings live
RiptOPL's master settings use settings_riptopl.cfg (with migration from conf_riptopl.cfg). That filename is separate from stock OPL's master config, but conf_network.cfg, app lists, per-game configuration and support files can still be shared. Favorites import from uOPL/wOPL is one-way: the next write saves RiptOPL's own OFAV format to favourites.bin, which those loaders cannot read back. Keep an original copy if you use them too. The settings home follows boot-directory discovery or Custom Settings Path; do not assume it is always mc0:/OPL/.
i Page return retention
Opening Start or Settings remembers the game/source page you paused on. Returning keeps that page selected while it is still visible; RiptOPL falls back to the first visible page only when the old page was disabled or removed.

Folder browsing

With Browse Folders in Game List on, subfolders of CD/ and DVD/ appear in the list as browsable entries instead of the loader flattening everything into one long list. It is off by default.

  • Folder rows sort to the top of the list, ahead of games, and are drawn with a trailing /. Within each group, entries sort by title.
  • Select opens a folder; the cancel button goes back up a level. (Which face button that is depends on your Select button setting — see Controls.)
  • A folder row has no info page and no per-game settings, so Square and Triangle do nothing on one.
⚠ Supported devices only
Folder browsing works on BDM devices (USB, MX4SIO, iLink, exFAT HDD), MMCE, and UDPFS in Files mode. It does not apply to the APA/PFS HDD or the PS1/VCD list, which do not scan a CD/DVD directory tree at all, nor to the UDPFS block device. SMB is not supported yet — its paths use a different separator and it is deliberately deferred. Turning the setting on simply has no effect on those pages.

Parental lock

Set a password in Parental Lock Password and save. Leave the field blank to disable the lock. An invalid password, such as the master override itself, is rejected.

What the lock actually gates

The parental lock guards configuration and destructive actions, not game launching. Anyone can still start any game on the list. What is behind the password:

  • Settings and the per-game / per-app settings screens (Triangle on a title)
  • Rename and Delete on a game entry
  • Network compatibility update and Start NBD Server
⚠ It is not a content filter
If your aim is to stop a particular game being played, the parental lock will not do it — it stops the library being changed, not played.

Setting, using and clearing it

To set one, enter a password in the field above and save. To remove one, clear the field and save — RiptOPL confirms with "Parental lock disabled."

Entering the correct password unlocks for the rest of the session: RiptOPL stops asking until the next restart, so you are not re-prompted between one settings screen and the next.

ℹ The master override disables the lock, it does not just unlock it
Entering the master override at the prompt does not grant one-time access — it deletes the stored password and writes the config immediately, showing "Parental lock disabled." After that there is no lock at all until you set a new one. The master password also cannot be chosen as your own: trying to set it is rejected with "Error - this password cannot be used."

POPSTARTER Network Settings

The POPSTARTER Network Settings row (also on PS Emulation Settings) opens POPSTARTER's own network files, IPCONFIG.DAT and SMBCONFIG.DAT, which PS1 games over SMB need. They are not RiptOPL's settings.

  • The screen shows what those files contain. If none were found, it says so and leaves the fields blank.
  • Import from SMB POPS Directory reads both files from the connected share's POPS folder. Nothing is written until you press OK.
  • The fields are the PS2's IP address type, IP, mask and gateway, then the SMB server's address, port, share, user and password.
  • OK writes only what you actually changed. On a first setup, with neither file on the card, saving the SMB values writes IPCONFIG.DAT too, as DHCP unless a complete static IP is entered. In the RetroAchievements build, the screen also holds the RetroAchievements telemetry and RetroAchievements badges switches.
i Apply and reconnect immediately
Confirming the Network page applies the current values and begins a fresh SMB connection attempt immediately; the explicit Reconnect action does the same without leaving the page. If the network page already shows a failed connection, Select / Refresh retries it there, without reopening settings or saving the whole configuration.

i Remembered L3 views
Wherever L3 does something, the view you leave a page on is remembered across reboots: every device page, the Favorites shelf and the APPS split side keep their own position. BDM pages save one position per device type (USB, iLink, MX4SIO, exFAT HDD, UDPBD), so a device keeps its view when the mass slot numbers swap between boots. Pressing L3 never writes to storage: a position rides along with a write that already happens — launching a game, or saving settings — so toggling and then powering off without doing either is the one case that is not kept. A remembered view the display pickers above no longer allow is discarded, not forced.

Where the audio comes from

Background music is Ogg Vorbis (.ogg). RiptOPL streams it rather than loading it into memory, so a long track costs no extra RAM. It looks in this order and takes the first that works:

  1. <theme>/sound/bgm.ogg — a disk theme's own music.
  2. The Default Theme Music path set above.
  3. THM/bgm.ogg under the active settings home — built-in themes only (<OPL> and <Coverflow>). A disk theme never falls through to this.

That order is why a disk theme with its own sound/bgm.ogg ignores your Default Theme Music setting: the theme wins. To use your own track everywhere, pick a theme that ships no music of its own.

The track plays through the console's audsrv, which only has converters for some sample rates: 44.1, 48, 32, 22.05 and 11.025 kHz in mono or stereo, and 24 or 12 kHz in stereo only. A file at any other rate, such as 16 kHz, plays no music at all; the menu carries on silently. Re-encode it at 44.1 kHz if in doubt.

Sound effects are PS2 ADPCM (.adp, 44.1 kHz), supplied by the theme in its sound/ folder. There are eight:

FilePlayed when
boot.adpRiptOPL starts (the Boot Sound setting)
cursor.adpMoving the cursor
confirm.adpConfirming
cancel.adpGoing back
message.adpA message or dialog appears
transition.adpChanging screen
bd_connect.adpA block device is connected
bd_disconnect.adpA block device is removed

The two built-in themes use effects embedded in the ELF and read nothing from the card. A disk theme supplying only some of the eight falls back to the built-in sound for the rest. See Theme Engine.

Per-game Settings (quick reference)

Press Triangle on a game to open its menu. Each screen is documented in full on the Per-game Settings page.

  • Configure GSM — GSM Selector, forced video mode, H-POS and V-POS, Emulate FIELD Flipping. Global or per-game. OPL core only. See GSM Video Modes.
  • Configure VMC — VMC Slot 1 and Slot 2 assignment, image creation and deletion, and keeping a physical card in a slot. See VMC.
  • Controller Emulation and Controller Macros — per-game pad emulation and macros. See PADEMU.
  • OSD Settings — OSD language, screen size and video mode. See OSD Settings above.
  • Save Changes, Test Changes and Remove Settings — save this game's settings, launch with them unsaved, or delete them.
  • Rename and Delete — only with Write Operations on, and never for PS2 games on the internal HDD. See Disk safety.
Which settings are greyed out under the Neutrino core?

OPL-only features are unavailable when a game is set to use the Neutrino core. In the per-game Game Settings screen the following are greyed (shown with a "Not used with Neutrino" hint): Modes 4 and 6 (Skip Videos and Disable IGR), Download Defaults, and the Configure GSM, Cheat Settings and Controller Emulation / Controller Macros screens. Modes 1/2/3/5 stay active because they map directly to Neutrino's -gc= flag. Mode 7 is Neutrino-only and is available (passes -gc=7 to Neutrino). DMA Mode, Game ID, Custom ELF, and VMC settings remain active regardless of core. See Per-game Settings.
